# IoT & Data Analytics Projects

A collection of applied data-engineering and IoT projects from earlier coursework and independent work, demonstrating the data/sensing side of the ICT Bioeconomy degree.

## Real-Time Monitoring System for 3D Printers and Mechanical Machines

Built a Python-based analytics platform that ingests sensor data from 3D printers and mechanical machines, tracks performance and health in real time, and raises alerts on anomalies. **Result:** reduced maintenance downtime by 25%.

## Temperature and Humidity Sensor with Raspberry Pi

Designed and deployed an IoT environmental-monitoring system: a Raspberry Pi collecting readings from DHT11 sensors, logged to a MySQL database for analysis. A small, complete example of the sensor → storage → analysis pipeline.

## Waste Management Data Analysis for Southwest Finland

Analyzed waste-collection data across 16 municipalities in collaboration with a regional waste-management company (Loimi-Hämeen Jätehuolto Oy), using Python and data visualization to identify route-optimization opportunities. **Result:** informed changes that helped reduce operational costs and improve collection efficiency.

## EcoOdyssey

Co-designed an educational card game promoting environmental sustainability awareness, combining physical game design with 3D-printed components and structured educational content.
